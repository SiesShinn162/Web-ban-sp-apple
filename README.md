# HoangPhanStore

Website thuong mai dien tu demo su dung HTML, Tailwind CSS, JavaScript, Node.js, Express va MongoDB.

## Yeu cau

- Node.js 16 tro len.
- MongoDB dang chay tren may.

## Cach chay nhanh tren Windows

1. Mo file `run.bat`.
2. Chon `3` de cai thu vien cho frontend va backend.
3. Chon `4` de nap du lieu mau vao MongoDB.
4. Chon `1` de chay toan bo du an.

Sau khi khoi dong:

- Frontend: `http://localhost:3000`
- Backend API: `http://localhost:5000/api`

Chon `7` trong `run.bat` de xem huong dan chi tiet.
